## Key Diagrams / Visual Structures to Draw in Exam

1. **CMM 5 Levels ladder** (pyramid or staircase — label each level with 1-2 characteristics)
2. **DMAIC cycle** (5 boxes in a loop: Define → Measure → Analyse → Improve → Control)
3. **PDCA cycle** (circular: Plan → Do → Check → Act)
4. **Fishbone diagram** (skeleton with at least 4 cause categories and sub-causes)
5. **Pareto chart** (bar chart + cumulative % line)
6. **Control chart** (line graph with UCL, average, LCL marked)
7. **QA vs QC table** (always good to draw this comparison table)

## Quick-Revision Cheat Sheet

### CMM Levels
1. Initial — Chaotic
2. Repeatable — Basic project management
3. Defined — Standardised processes org-wide
4. Managed — Quantitatively controlled
5. Optimising — Continuous improvement

### TMMi Levels
1. Initial — Ad-hoc testing
2. Phase Definition — Test planning, monitoring
3. Defined — Org-wide test strategy, test org
4. Managed — Peer reviews, advanced techniques
5. Optimisation — Defect prevention, test process improvement

### Six Sigma DMAIC
- **D**efine the problem
- **M**easure current performance
- **A**nalyse root causes
- **I**mprove the process
- **C**ontrol the improved process

### Ishikawa's 7 Tools
1. Fishbone / Cause-Effect Diagram
2. Pareto Chart
3. Histogram
4. Control Chart
5. Scatter Diagram
6. Check Sheet
7. Flowchart / Stratification

### CASE Tool Categories
- **Upper CASE** — Requirements, Design (Jira, Enterprise Architect, Figma)
- **Lower CASE** — Coding, Testing, Deployment (SonarQube, Selenium, Jenkins)
- **Integrated CASE** — Full SDLC (Azure DevOps, Rational Suite)
