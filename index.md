## Unit Summaries

### Unit 1 — Software Testing Basics
Core vocabulary and concepts. Covers error/fault/defect/failure chain, V-Model, STLC phases, 7 testing principles, reviews (inspection vs walkthrough), and TDD.

**Key topics:** V&V · V-Model · STLC · Definitions · Testing Principles · Reviews · TDD

---

### Unit 2 — Testing Techniques
Black-box and white-box techniques. Covers ECP, BVA, decision tables, cause-effect graphing, state transition, CFGs, cyclomatic complexity, data flow, loop testing, mutation testing, and JUnit.

**Key topics:** ECP · BVA · Decision Table · CFG · Cyclomatic Complexity · Mutation Testing · JUnit

---

### Unit 3 — Levels of Testing & Defect Management
Functional and non-functional testing levels. Covers unit/integration/system/acceptance testing, load/stress/performance testing, defect lifecycle, defect repository, and defect prevention.

**Key topics:** Unit Testing · Integration Testing · UAT · Load/Stress Testing · Defect Lifecycle · Defect Prevention

---

### Unit 4 — Software Test Automation
What to automate, how to architect automation frameworks, tool selection, and advanced test generation. Covers POM, data-driven frameworks, random testing, and property-based testing.

**Key topics:** Automation Scope · Framework Architecture · POM · Tool Selection · Random Testing · Property-Based Testing

---

### Unit 5 — Software Quality Assurance
Process quality and standards. Covers SQA, CMM/CMMI levels, TMMi, ISO 9001, Six Sigma (DMAIC), Ishikawa diagram, 7 quality tools, and CASE tools.

**Key topics:** SQA · CMM · CMMI · TMMi · ISO 9001 · Six Sigma · Ishikawa · CASE Tools

---

### Unit 6 — AI/ML Testing
Testing for AI and machine learning systems. Covers why AI testing is different, challenges (oracle problem, bias, drift), testing approaches, tools (Great Expectations, Fairlearn, Evidently AI), and case studies.

**Key topics:** Oracle Problem · Bias Testing · Data Drift · Metamorphic Testing · Adversarial Testing · Fairlearn

---
