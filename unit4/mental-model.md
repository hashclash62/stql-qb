# Unit 4: Software Test Automation — Mental Model

## How the Topics Connect

```
Why Automation? (benefits, limitations)
        |
        v
Scope of Automation (what to automate, what not to)
        |
        v
Skills needed for Automation
        |
        v
Design & Architecture for Automation
        |
        v
Requirements for a Test Tool  →  Tool Selection
        |
        v
Challenges in Automation
        |
        v
Automated Test Generation
    ├── Random Testing
    └── Property-Based Testing (Real-Time Systems)
```

The story: understand WHAT automation is → WHAT to automate → WHO does it → HOW to architect it → WHICH tools to use → CHALLENGES → ADVANCED techniques (random + property-based).

---

## Topic Groups

### Group 1 — What is Automation + Scope (01)
- Definition of test automation
- Objectives
- What types of testing are amenable to automation
- What should NOT be automated
- Scope: stable features, regression, performance

### Group 2 — Skills for Automation (02)
- Technical skills (scripting, frameworks)
- Testing knowledge (test design, defect tracking)
- Domain knowledge
- Junior tester skill set

### Group 3 — Design and Architecture (03)
- Automation architecture components
- Linear / Modular / Data-driven / Keyword-driven / Hybrid frameworks
- Page Object Model for web apps
- V&V model and automation
- Remote execution — test console + execution machines

### Group 4 — Tool Requirements and Selection (04)
- Requirements for a test tool (per category)
- Factors influencing tool selection
- Tool deployment
- Tools by category (functional, performance, test data, reporting)

### Group 5 — Challenges in Automation (05)
- GUI test fragility, UI changes
- Pop-ups and interruptions
- Config file management
- Maintenance overhead
- DevOps environment challenges

### Group 6 — Automated Test Generation (06)
- Random testing
- Property-based testing (PBT)
- Real-time systems (traffic control, banking)
- PBT vs random testing comparison
